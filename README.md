Schoolproject voor Backend Development (2025/2026). 
Bevat een Full-stack project voor een reserveringssysteem voor camping/hotel Le Marconnes, 
waarbij gebruikers eerst moeten registreren op de webapplicatie, en vervolgens een reservering kunnen maken na succesvolle authenticatie met een klantaccount. 
API endpoints zijn beveiligd met JWT Bearer tokens (authenticatie & authorisatie) 
Medewerkers en beheerders hebben een eigen rol met eigen authorizatielevels. 'Admin' rol kan bijvoorbeeld als enige alle API endpoints benaderen. Employee rol kan alleen GETs doen, Customer kan alleen public endpoints + POST reservation endpoint gebruiken.
